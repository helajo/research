# Before You Fork · 复刻（fork）之前

A bilingual (English / 中文) cybersecurity workshop: seven questions to ask before you clone, install or connect any
GitHub project, worked through on LobeHub (v2.3.2, checked 11 Nov 2026), with a project scorer, a checklist, a
hands-on exercise and the sources for every fact.

双语（English / 中文）网络安全研讨会资料：克隆、安装或连接任何GitHub项目之前要问的七个问题，以LobeHub（v2.3.2，
2026 年 11 月 11 日检查）为例逐项演示，附项目评分工具、检查清单、动手练习以及每条信息的出处。

Educational guide only; not professional security, legal or investment advice.
仅供学习参考，不构成专业安全、法律或投资建议。

## Update the page · 更新页面

```bash
cd before-you-fork/source
python3 build.py          # rebuild artifact.html and ../index.html from content.json + template.html
node check.js             # optional: browser checks (Playwright); expect "0 failures"
```

Then republish `source/artifact.html` to the artifact link above (ask Claude to publish it to that URL), and commit.
LobeHub moves fast: re-run the seven questions on the latest release before reusing the findings.

然后把 `source/artifact.html` 重新发布到上面的artifact链接（可请Claude发布到该链接），再提交。LobeHub更新很快，
复用结论之前，请先对最新版本重新检查七个问题。

## How it was made · 制作方式

Five Claude agent teams, then a final read-through before publishing:
1. Security research: LobeHub file review with file and line evidence, 15 advisories, 4 real incidents.
2. Connecting-safely research: API keys, app permissions, AI agents, IP and identity, Claude and your data.
3. Bilingual writers: all text in English and Simplified Chinese, facts only from the research files.
4. Builder: the page, the language toggle, the scorer and checklist, browser checks.
5. Reviewer: fact check, Chinese and English editing, accessibility and contrast, re-run of all checks.

由五个Claude智能体团队完成（安全研究、安全连接研究、双语写作、页面构建、审校），发布前再通读全文。
