Before you fork

Put together, LobeHub is a genuine, actively maintained project with a working security process. Both High findings are in its self-hosting Docker files: built-in secrets and passwords that must be replaced, and database ports open to every network. So: reading or forking it is fine; for using it, the hosted version or the official desktop app avoids most of this list, because we never run its install scripts or its database ourselves. These findings are as of v2.3.2; v2.3.3 came out on 12 November, so check the latest release first.
