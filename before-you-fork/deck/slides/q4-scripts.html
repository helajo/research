Does it run downloaded scripts?

IN LOBEHUB

Medium

The README’s one-line setup:

bash <(curl -fsSL
https://lobe.li/setup.sh)

The short link runs whatever is on the default branch that day: no fixed version, no checksum.

Check

Any setup line that pipes a download straight into bash, sh or PowerShell.

Why it matters

You can’t read the script before it runs, and a short link can be pointed somewhere else at any time.

Stay safe

Download the script, read it or ask Claude to, then run your own saved copy.

Before you fork

“curl into bash” is everywhere because it’s convenient. We rate it Medium: the script itself can be read in the repository (docker-compose/setup.sh) and doesn’t need administrator rights, but what actually runs is whatever a third-party short link points to on the day, and the script then downloads more files from the main branch, also unpinned. The same one-liner on an unknown project, or in a YouTube tutorial, is exactly how many laptops get infected. Save it, read it, then run it.
