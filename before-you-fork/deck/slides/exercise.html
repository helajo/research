Hands-on · 15 minutes

Your turn: check one project

0–2 min

Pick a project from github.com/trending, or one you’ve wanted to try.

2–4 min

Answer questions 1 and 2 from its GitHub page, including the LICENSE file and latest release.

4–10 min

Clone it, don’t install it. Switch Claude Code to Manual mode, then give it the “before you install” prompt.

10–13 min

Rate it on the seven questions in the workshop page’s scorer: OK, Low, Medium or High.

13–15 min

Share one finding: what it is, why it’s an alert, how to prevent it.

Before you fork

Pairs work well: one person drives, one reads Claude’s answers aloud. When Claude flags something, ask it why it is an alert and how an attacker would use it, then google the term. The scorer on the workshop page gives a Go / Proceed with care / Stop verdict from the seven ratings.
