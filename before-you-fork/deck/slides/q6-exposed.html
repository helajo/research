What’s exposed when it runs?

IN LOBEHUB

High

The Docker setup opens the database (5432), Redis (6379) and file storage to every network the computer joins.

Redis has no password; the database password is printed in the repo.

Anyone can sign up, and the storage bucket is publicly readable.

Check

Which ports it opens and to whom, default passwords, public storage, and who can sign up.

Why it matters

Attackers use search tools such as Shodan to find open ports and default passwords. Devices on the same Wi-Fi may reach them too.

Stay safe

Bind ports to 127.0.0.1 (this computer only), set your own passwords, and limit sign-up to your team.

Before you fork

A port is a door into your computer. Open on every network means other devices can try that door; 127.0.0.1 means only this computer. CISA names Shodan and Censys as tools attackers use to find exposed systems with default passwords and old software. In LobeHub’s default Docker setup, a database with a password printed on GitHub and a Redis with no password are both open, on a server that can hold API keys and run agents. One good sign: its search database is deliberately kept private. The fixes are a few lines (127.0.0.1, your own passwords, AUTH_ALLOWED_EMAILS), but you only make them if you know to look.
