Eight words to google this week

Supply-chain attack

A trusted library is hijacked and reaches everyone who installs it.

Phishing

A fake email or page that steals a password, as in the chalk case.

postinstall script

Code a package runs by itself when you install it.

IP address and VPN

Your internet return address, and a service that swaps in its own.

Lockfile

A list of exact versions, so every install gets the same files.

0.0.0.0 vs 127.0.0.1

A port open to every network, or to this computer only.

XSS to RCE

A web-page bug that turns into control of your computer.

Least privilege

Give each key, app and AI agent only the access it needs.

Before you fork

These eight cover everything in today’s session. A good way to learn them: when Claude flags something, ask it “why is this an alert, and how would an attacker use it?”, then google the term to see real cases.
