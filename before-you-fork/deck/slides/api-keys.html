Connecting safely

Treat API keys like credit cards: one per shop, each with a limit

One key per tool

A separate key for each app, script and teammate. If one leaks, revoke only that one.

Set a hard spending limit

An alert only notifies you; a hard limit stops requests. Give each app its own Claude workspace with a spend limit.

Grant the least access

Give keys an expiry date. When an app asks to connect Drive, GitHub or email, read the permissions first.

Never in chat or code

No keys in chats, screenshots or code. If one slips out, revoke it first: deleting the message doesn’t help.

Before you fork

Tools like LobeHub only work by connecting to other services, and each connection is a key or a permission. An API key is like a credit card number: whoever has it can spend on your account. In OpenAI, turn on “Enforce a hard limit” (spending can still run slightly over before it takes effect). In the Claude Console, the Default Workspace can’t take a spend limit, so give each app its own workspace. GitHub scans public repositories for Claude and OpenAI keys and tells the provider, and Anthropic switches off an exposed key automatically, but don’t rely on that. Turning a tool off inside LobeHub doesn’t revoke its access to your Google or GitHub account; revoke it there too.
