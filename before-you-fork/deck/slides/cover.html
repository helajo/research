Before you fork: a security check for any project you download

Seven questions to ask before you clone, install or run code from the internet. Worked example: LobeHub, the AI agent workspace we are testing.

Prepared with Claude Code · LobeHub v2.3.2, checked 11 Nov 2026

Welcome. Today is not about installing LobeHub. It’s about the habit of checking any project before it touches our laptops. We’ll use LobeHub as the example because we did exactly this check on it last week. By the end, everyone should be able to run the same check on any GitHub project in ten minutes, with Claude doing most of the reading.
