Safe install checklist

01

Take the link from the official site; check the owner, activity and LICENSE file.

06

Never pipe a download into bash: save it, read it, then run it.

02

Read SECURITY.md and the Security tab; install the latest release.

07

Bind ports to 127.0.0.1, replace every sample password and key, limit sign-up.

03

Ask Claude to review the repository, read-only, before installing.

08

One API key per tool, each with an expiry, a hard spending limit and least access.

04

Prefer the hosted app or official release to building from source.

09

Keep agent approvals on (Manual, Ask), give it one folder, fork Actions off.

05

If you must build, use a separate virtual machine, never a work laptop.

10

Hide your GitHub email, use your phone’s hotspot for sensitive work, redact screenshots.
