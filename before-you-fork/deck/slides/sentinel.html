Claude as sentinel

Ask Claude before you install, share or connect

1 · BEFORE YOU INSTALL

Check this repository before I install it. Read files only; don’t run anything. List install scripts, download-and-run lines, secrets, open ports, default passwords and what it can do on my computer. Rate each risk with the file and line, and say how to prevent it.

2 · BEFORE YOU SHARE

Before I share this screenshot, log or file, check it for API keys, passwords, tokens, email or IP addresses and personal details. List what to remove. Don’t repeat any secret in full.

3 · BEFORE YOU CONNECT

This app asks for these permissions: [paste]. What could it do with them, and what is the least access that still works?

Pasted text goes to the AI service: replace known keys with placeholders. Claude is a second pair of eyes, not a guarantee.

Before you fork

This is the habit our boss described: use Claude as a sentinel before we hand anything over. Three moments: before installing a project (Claude Code reads the folder; switch it to Manual mode first), before sharing something (a screenshot or log can carry keys and addresses), and before connecting an app. Describe the thing; never paste the secret. If a key is pasted by mistake, treat it as leaked and revoke it, because deleting the chat doesn’t undo it. On personal Claude plans, chats are used for training only when the “Help improve” setting is on (kept up to 5 years; 30 days when off); Incognito chats aren’t used for training. Work data belongs in a plan IT has approved. The bilingual workshop page has these prompts in English and Chinese with copy buttons.
