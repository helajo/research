What can it do on my machine?

IN LOBEHUB

Medium

The desktop app can read, write and move files and run commands. Commands ask first; file changes in the working folder don’t, and auto-run approves everything.

Plugin (MCP) tools can be set to Allow, Ask or Deny.

32 GitHub workflows; one syncs a fork every 6 hours if Actions are on.

Check

Can it write files, run commands or add plugins without asking? Which approval mode is the default?

Why it matters

An AI agent that writes code to your computer acts as you. One bad plugin or hidden instruction, and so does an attacker.

Stay safe

Keep approvals on (Manual, and Ask for plugins). Give it one folder. Leave Actions off on the fork.

Before you fork

This is the new risk that comes with AI tools, and the one our boss flagged: these apps don’t just chat, they write files and run commands on your laptop. LobeHub’s own docs warn that not every write operation is guaranteed to ask, and that the working folder is not a security boundary. A local plugin (MCP server) is a program running with your permissions. Past bugs let a malicious chat message or diagram run commands; all are fixed. The same goes for Claude Code: its default auto mode does not ask before every command, so switch to Manual mode for unfamiliar projects. Never switch any agent to approve everything on your own laptop.
