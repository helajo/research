Question 1 of 7

Is it the real project?

IN LOBEHUB

Low

Genuine project. Our copy is the team’s fork, helajo/lobehub, at v2.3.2 (11 Nov 2026); v2.3.3 came out the next day.

package.json says “MIT”, but the LICENSE file is the LobeHub Community License, which adds conditions.

Check

The owner and link match the official website. Recent releases. Read the LICENSE file itself.

Why it matters

A look-alike copy can carry changed code. A fork can fall behind and miss security fixes.

Stay safe

Take the link from the official site, not an ad or a video description. Use the latest official release.

Before you fork

Two minutes on the GitHub page. Look at who owns it, whether the official website links to it, when it was last updated, and whether there are proper releases. LobeHub is genuine, but we rate it Low rather than OK for two reasons: the licence information disagrees with itself (package.json says MIT, the LICENSE file says LobeHub Community License, which needs a commercial licence for derivative products), and our checked copy was already one release behind a day later. Lesson: read the LICENSE file itself, and always check the latest release.
