Question 3 of 7

What runs when I install it?

IN LOBEHUB

Medium

Install scripts are allow-listed: 6 outside packages may run their own scripts, 7 are blocked.

No lockfile for the main app: every install takes the newest versions of 421 direct dependencies.

Check

Look for install scripts in package.json files, and for a lockfile that pins exact versions.

Why it matters

This is the supply-chain attack’s favourite door: one hijacked library, and its script runs as you.

Stay safe

Use the hosted app or the official desktop release. If you must build, use a separate virtual machine.

Before you fork

This is how Shai-Hulud spread. When you type “install”, the package manager downloads hundreds of libraries and some of them run their own setup code with your permissions. LobeHub does one thing well here: only six named packages may run install scripts. But a lockfile records exact versions so every install gets the same files; without one, you get whatever is newest that day, including a version an attacker published yesterday. Also note: the project’s prepare script quietly switches on its own git hooks, which then run on every commit.
