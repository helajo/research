1️⃣ Natural-Language Backtesting · 自然语言回测

中文摘要:用一句话描述交易策略,系统自动生成代码、拉取真实历史数据回测,输出夏普比率、最大回撤、收益率等指标。支持美股、港股、A股、加密货币、期货、外汇。

Describe any strategy in plain English — it writes the code, runs it on real historical data, and reports Sharpe ratio, max drawdown, and returns.

# Moving average crossover on US equities
vibe-trading run -p "Backtest a 20/50-day moving average crossover on AAPL for the past year, show Sharpe ratio and max drawdown"

# RSI mean-reversion on crypto
vibe-trading run -p "Test RSI(14) mean-reversion on BTC-USDT: buy below 30, sell above 70, last 6 months"

# Multi-factor strategy on A-shares
vibe-trading run -p "Backtest a momentum + value + quality multi-factor strategy on CSI 300 constituents over 2 years"

3️⃣ Alpha Zoo — 461 Pre-Built Quant Factors · 预置量化因子库

中文摘要:内置461个量化因子:alpha101(Kakushadze 论文)、gtja191(国泰君安191因子)、qlib158(微软 Qlib)、学术因子(Fama-French 等)。一行命令即可在指定股票池上测试因子表现(IC、IR 排名)。
vibe-trading alpha list --zoo gtja191 --theme reversal --limit 10   # browse catalogue
vibe-trading alpha show gtja191_171                                  # inspect one factor
vibe-trading alpha bench --zoo gtja191 --universe csi300 --period 2018-2025 --top 20
vibe-trading alpha compare gtja191_171 gtja191_111 gtja191_163 --sort ir
vibe-trading alpha export-manifest                                   # export factor manifest

4️⃣ Multi-Agent Swarm Teams · 多智能体研究团队

中文摘要:30个预设团队模拟投资委员会、量化策略台、加密交易台、宏观利率外汇台等,多个AI角色辩论并输出研究报告。注意:消耗大量 token,Gemini 免费额度可能触发限流,建议少量使用。

# Global macro portfolio allocation

💡 Suggestions · 建议

中文摘要:先做一次小测试验证配置;注册 MCP 后可与现有 /stock 报告流程结合;蜂群模式耗 token 需节制;远离 connector(券商连接)命令保持纯研究模式。
  • Smoke test first: vibe-trading run -p "Get the latest quote and 1-month trend for AAPL" — verifies the Gemini key + data pipeline cheaply.
  • Register MCP (command in the Setup section above) so Claude Code can combine vibe-trading backtests with your existing /stock HTML reports.
  • Swarms are token-hungry — many LLM calls per run; watch Gemini rate limits.
  • Try Shadow Account if you can export real trade history — the most unique feature, fully local/read-only.
  • Avoid connector commands — they wire up live brokers. Everything above works without them.
✅ Safe by default: no broker connected, free data only, nothing can place trades.
